# Riyasaat Ahmed Rahul

**Full-Stack Engineer for AI products** · React, Next.js, TypeScript, Python

Founding full-stack engineer on [Martlet.ai](https://martlet.ai) at [John Snow Labs](https://www.johnsnowlabs.com), where I also work on the Patient Journey platform (clinical NLP). I take LLM and NLP features from the backend to the screen and own the stack behind them.

What that has looked like in practice:

- Unblocked a **$1.2M** health-plan contract by taking a clinical platform to **WCAG 2.2 AA** (180+ violations closed)
- Lifted AI suggestion adoption from **22% to 71%** with a generative UI that shows the evidence behind every score
- Saved each medical coding team **18 hours a week** by automating ICD coding and RAF scoring
- Cut the wait for the first AI suggestion from **12s to 380ms** and abandonment **48%** by streaming over SSE
- Built HIPAA de-identification for text, PDF, FHIR and DICOM, scaled to **5 GB** imaging files and **500-page** PDFs
- Cut failed job submissions **84%** with an offline-first PWA for field technicians
- Built a **62-component** design system adopted by 4 squads, cutting new-screen delivery time **41%**
